# Simple Calculator 🧮

A basic calculator web app built using **Node.js**, **Express**, and **EJS**.  
It allows users to input two numbers, select an operation (`+`, `-`, `*`, `/`), and get the result instantly.

---

## 🚀 Features

- Add, subtract, multiply, and divide two numbers.
- Simple and clean UI.
- Uses **EJS templating** for rendering.
- Handles **form submissions** with POST routes.
